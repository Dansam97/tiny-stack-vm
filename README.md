A tiny stack virtual machine for make.fun's 32-bit stack ISA: a 256-value stack, 64-deep calls, 256 words of memory, wrapping arithmetic, and all ten traps with their exact exit codes. One `main.ts` answers all 40 instances deterministically in well under a second.

## Run it

```sh
MAKEFUN_INPUT_DIR=/input MAKEFUN_OUTPUT_DIR=/output node main.ts
```
